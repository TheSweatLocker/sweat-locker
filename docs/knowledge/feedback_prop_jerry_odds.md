Props surfaced by Prop Jerry should be in the -300 to +150 odds range — the goal is parlay legs, not longshot bets.

**Why:** User wants actionable props users can add to parlays, not extreme longshots like NHL goals at +3300.

**How to apply:** When working on Prop Jerry or any prop scanner, filter to parlay-friendly odds range. Use median odds (not average) for true probability to resist outlier books. One stale book at +450 when the market is -114 is noise, not an edge.
