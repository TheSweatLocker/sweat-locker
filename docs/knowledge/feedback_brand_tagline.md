The canonical Sweat Locker tagline is **"More Data, Less Sweat"** — adjective+noun parallel to "More Data". NOT "More Data, Sweat Less" (which I used incorrectly in earlier brand sweep + website rewrite).

**Why:** Andy corrected this on 2026-05-07 after spotting "MORE DATA. SWEAT LESS." in the home header. The grammatical structure should match: "More [noun]" + "Less [noun]" — both are quantity comparisons. "Sweat Less" is verb-form which breaks the parallel.

**How to apply:** Anywhere the tagline appears, use:
- Long form: "More Data, Less Sweat."
- Short form / header all-caps: "MORE DATA. LESS SWEAT."

Old "Bet Smarter, Sweat Less" is fully retired. Don't reintroduce.

Affected surfaces (all should match):
- App home header: "MORE DATA. LESS SWEAT."
- App settings/profile: "More Data, Less Sweat."
- Website hero / footer
- Privacy/ToS marketing copy (if any uses tagline)
- Social card sign-offs / hashtags
- App Store description
