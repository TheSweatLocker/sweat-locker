Jerry's MLB game reads should be **structured markdown with section headers**, not compressed 2-3 sentence summaries. Casual bettors find dense one-paragraph reads hard to digest even when the content is good.

**Format Andy asked for (MLB):**
- **The Setup** — matchup frame, Sweat Score tier as context
- **The Pitcher Matchup** — xERA, K rate, L3 form, handedness
- **Lineup Quality** — wRC+, platoon-adjusted vs opposing hand
- **Total Lean** — projected vs posted with delta
- **Where the Model Sits** — overall signal state, ML/NRFI
- **The Play** — directional take

**Sign-off rule:** NEVER repeat closing phrases. "That's where the model sits" used on every read is a tell that Jerry is templated. Rotate naturally — "data points to...", "signals align on...", "edge lives on...", "model's angle here...", etc.

**Why:** Andy feedback on 2026-04-22 after reviewing live Jerry reads — structured format "felt more like an actual sharp analyst writing a game prep" vs the compact 3-4 sentence format. Also noticed the identical closing line felt templated.

**How to apply:** MLB and NBA get structured multi-section format (they have rich model data). UFC keeps its 3-sentence model/analysts/divergence structure (different purpose). NCAAB and NHL can stay compact — less data to spread across sections. Length can exceed old 2-3 sentence cap — let each section breathe, but skip sections with no data.

**Signal coverage:** Jerry should reference every material pipeline signal available (streak, rest, weather, park, ump, platoon, form drift, etc) AND briefly tie it to why it matters in this specific matchup — not just list signals. Example of the voice: "Mets on a 12-game skid, due for bounce-back, but with today's lineup matching up against [pitcher], it's hard to see that happening here." Connect each signal to outcome implication, sharp-analyst style. Silent signals (available data that gets no mention) are wasted context.
