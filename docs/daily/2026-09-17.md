## Home banners system (new — server-driven, 2026-09-17 late PM)

Per Andy directive: "server side for all these notes and specific
notes for sports as needed." Full docs in `docs/TECHNICAL_REFERENCE.md`
Section 9 — this is the runbook.

**Table:** `public.home_banners` (migration `20260917d`)
- `icon`, `message`, `deep_link` (sharp/ladder/ledger/daily_degen/jerry)
- `sport` (NULL = all), `route` (NULL = all), `priority`, `expires_at`
- `origin` = 'auto' (cron) or 'admin' (manual SQL push)
- `kind` = stable id for cron UPSERT dedup

**Client:** `app/components/HomeStreakBanner.tsx` — polls every 5 min,
filters by sport + route, sorts by priority DESC, rotates top-3 every 8s.
Zero hardcoded templates. Deep-link string routes tap to tab-switch.

**Auto-cron:** `mlb_pipeline/compute_home_banners.py` — 5 classes
(Prime Props L7D, Sharp 3d hot, Sport 7d run, Daily Degen streak,
Ledger green streak). Priority 100/90/80/70/60. 24h TTL.

**To brief anything hot without a client rebuild:**
```sql
INSERT INTO home_banners (icon, message, deep_link, sport, route, priority, expires_at, origin)
VALUES ('🏈', 'NFL Sunday early slate — 5 PRIME plays live', 'sharp',
        'NFL', 'home', 85, NOW() + INTERVAL '6 hours', 'admin');
```

Kill early: `UPDATE home_banners SET expires_at = NOW() WHERE id = <id>;`

Change auto-template: edit `compute_home_banners.py` + rerun (`python
mlb_pipeline/compute_home_banners.py`). Change threshold: same file.
No client work either way — copy is visible within 5 min poll cycle.
