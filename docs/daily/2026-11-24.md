### Why `edge_weight` cannot see it

The bar is `max(side_baseline, flat market breakeven)` — never the price the
signal actually fires at. Confirmed by calling it:

```
side_baseline('NCAAB','ml','HOME_ML') = 0.666   (= registry baseline_pct 66.6)
market_breakeven('ml')                = 0.5833
bar used                              = max(0.666, 0.5833) = 0.666
ncaab_home_efficiency_edge: hr 97.73, n=44  ->  weight 0.8202
```

97.73% against a 66.6% bar is +31pp, which saturates the edge curve. But the
games it fires on are heavy home favourites priced near -1250, where
**breakeven is ~92.6%** — and the refit measured the realised return at
**-6.89%**. The signal clears both bars the scorer knows about and loses money
against the one it does not.

The side baseline barely helps here: with it, 0.8202; without it, 0.8237.
Once a rate is 30pp over the bar the curve is already saturated, so the
2026-10-28 side-baseline fix cannot reach this class of signal.

### Why the auditor that exists does not catch it

`audit_read_pick_consistency.py` was written for exactly this on 2026-10-29
("i need verification that each Jerry game read write up matches the picks")
and **is scheduled in `ncaab_pipeline.yml`**. Two reasons it is silent:

1. **The ml tier cap switched the gate off.**
   `ensemble_scorer.MAX_TIER_BY_SPORT_MARKET = {('NCAAB','ml'): 'COVERAGE'}`
   caps every NCAAB moneyline to COVERAGE, and the auditor's contradiction
   rules are gated on
   `actionable_tier = _tier not in ('COVERAGE','PASS','SKIP','NO_PLAY')`.
   **308 of 350 NCAAB ml reads (88%) are COVERAGE**, and **51 of the 73
   flagged reads sit on a skipped tier.** A cap in the scorer silently
   disabled a gate in the auditor --
   `feedback_absent_key_makes_a_gate_dead`.
2. **Rule 4 has no converse.** It checks that a *total* pick's prose says
   "over"/"under". Nothing checks that an *ml/rl* pick's prose does NOT
   conclude on a total. **10 of the 73 are tier LEAN** -- actionable, and
   still uncaught.

**In fairness to the gate:** the tier exclusion is deliberate and documented
(`feedback_a_detector_must_know_the_intentional_case`) -- COVERAGE reads are
excluded from the Sweat Card outright so every game can carry a read without
selling it as a play. A COVERAGE contradiction sells nothing. But the prose
still renders in game detail, so the user reads it, and for NCAAB the
exclusion removes 88% of the sport's biggest market from any check at all.

The fix is narrow and matches the file's own stated standard (PRECISION OVER
RECALL, structured claims only): a closing sentence naming `<over|under>
<number>` is as unambiguous as the projected-score rule it already trusts, so
it can be checked at **every** tier without crying wolf. Judging whether a
paragraph *argues a side* still needs a model, and that is correctly out of
scope.
