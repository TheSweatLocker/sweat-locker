  pull. Prose froze Wednesday, picks kept moving. (e1fb9533)

  NCAAF equivalent added (Thu 8am -> Sun night). Andy's rule: "lock it
  Thursday, no changes unless something significant happens; lock
  college before the weekend."
- **jerry_pick_scrub was never wired into the football pipelines** — it
  has supported NFL/NCAAF since it shipped but only ever ran
  `--sport MLB`. Now in both.
- **The flip detector could never have fired for football anyway**: it
  searched for the literal phrase "take <team>" against the raw ctx
  value, but NFL ctx stores ABBREVIATIONS (CHI) while prose writes city
  names (Chicago). Rewritten around aliases + recommendation patterns.
- **NFL side/line metadata repaired on today's slate.** 3 picks had
  `side` pointing at the opposite team from the label (all three on
  favourites laying points; every dog pick was correct; NCAAF clean at
  0/69), and those same 3 had `line = None`. grade_jerry_reads grades
  off call_side + call_line, so they would have graded on the WRONG
  TEAM, or been ungradeable. Caught before grading; 0 historical rows
  affected. All 14 now verify consistent.
  NOTE: the generator bug is NOT fixed — ensemble_scorer emits
  `top.side` opposite `top.display_label` for favourite spread picks,
  and omits the line. That is shared cross-sport code and the slate was
  locked, so only the data was repaired. **Fixing the generator is a
  queue item.**
