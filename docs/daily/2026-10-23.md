### And the override is NOT losing — it is slightly winning

The defect is not the direction, it is that **a silent divergence is
indefensible either way**. If we deliberately publish against a read, the
product has to say so and the read has to be graded as the losing opinion it
was. Right now a user reading the Bears write-up saw CHI and a receipt saying
we lost on NE.
