### `validate_signals.py` — three states, never two

VALIDATED / ANTI_VALIDATED / **UNDETERMINED**. A signal with no attribution
rows is UNDETERMINED (a backlog item), never a negative verdict.

Verified before use, printed every run:
- `signal_was_right` grades **the side the signal named**, not ours: it
  mirrors our own result **98.7%** when the signal agreed and **2.4%** when
  it disagreed, i.e. independently correct. (`result` on the same row IS our
  pick's outcome — averaging that punishes a signal for disagreeing.)
- `close_line` is the HOME line: `margin + close_line > 0` reproduces our
  graded rl results on **2937/3223 = 91.1%**.
- `ml` is graded as WIN not COVER: `signal_was_right` matches `margin>0` on
  **1268/1268 = 100.0%**, the spread test on 81.7%.

Two bugs in my own first run, both caught before shipping:
1. grouped by `signal_key` alone, so all six sports got the **pooled**
   total — `home_ats_hot_at_home` printed n=60 / 61.7% identically for
   every sport. Now keyed `(signal_key, sport)`.
2. graded `ml` against the spread, so the NCAAF ml HOME control read 50.6%
   instead of the real **59.3%** home win rate. Fixing it **revoked** a
   VALIDATED: `ncaaf_home_field_baseline` 65.7% n=108 was a home bias with
   extra steps.

Live result: **VALIDATED 1, ANTI_VALIDATED 0, UNDETERMINED 859** (666 never
measured). Only **16** signals have n≥30 inside their own sport. The one
survivor is `ncaaf_projected_spread` **73.0% n=74** ml HOME vs a 59.3%
control. ANTI_VALIDATED being **zero** is the finding: nothing has enough
data to be confidently bad either, so the 273 disabled signals were turned
off on no evidence.

### My own script printed a false EDGE, and the guard caught it

First NHL output: *model-favoured side 62.9% n=264, EDGE.* Wrong, three ways:
- `close_spread` is **exactly ±1.5** (2 distinct values) and median
  |projected margin| is **0.60**, so the sign of the gap is set by the
  **line**, not the model → added an **inert-model** detector (the model
  names the dog on **88.8%** of games).
- **ALWAYS take the +1.5 dog = 61.9%**. The model adds **+0.7pp**. The
  "edge" was the line's.
- A fixed handicap is not priced at −110: `close_puckline` dog prices run
  **−192/−210**, break-even **65.8–67.7%**. So 62.7% **loses money**.

Now reads UNDETERMINED against a 61.9% bar, with the price warning. Four
controls instead of one: blanket HOME, blanket AWAY, always-the-line's-dog,
and a mix-matched control holding the model's own home/away split.
