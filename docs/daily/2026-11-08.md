## Andy's "bunch of 55s" — measured

NFL Sunday, 13 games, **zero PRIME and zero STRONG**. Conviction: 55×7,
60×4, 54×1, 45×1. The ensemble formula is
`50 + min(score*10,30) + min(margin*20,15)`; today's NFL scores run
0.13–1.31, so `base` lands 51–63. Raw 61 → `scaled` 65 against a POTD bar
of **70**. So today's "no play" POTD is honest: NFL's best opinion sits

### conviction 0 is NOT a bug — checked before "fixing" it

NHL showed conviction 0 on four games carrying real scores (0.13, 0.08,
0.06, 0.43) while a score of *exactly* 0 gave conviction 50 — backwards, so
I went looking for the overwrite. The scorer clamps `max(45, min(97, …))`
and can never emit 0. `defensive_gates.apply_nhl_ml_confidence_gate` sets
conviction to exactly **0** to mean *"has not earned a stake"*, stamps its
own audit_note, and `compute_surface_records` then skips `conviction==0`.
Deliberate.

**But it is expressed as a falsy zero**, so a client doing
`Number(conviction) || 55` renders a withdrawn pick as "55% confidence" on
a LEAN badge — the defect that reached 58 live cards on 11-03.

## "?-15" was user-visible on four NFL games

`signal_expr.render_prose` turns an unresolvable `{key}` into a literal
`?`, silently. `nfl_home_qb_recent_home_hot`'s template asked for
`{home_qb_recent_home_wins}` — not a column, ever. The chip read **"Home QB
Drake Maye ?-15 last home starts"**: 9 live chips since 11-01, 4 of 13
games today. The signal's *condition* was always right (it reads
`win_pct`), so it fired correctly and looked broken doing it.

I nearly reported **60** broken placeholders — a static scan of
`display_prose_template` against context columns flags 60 uses. Scanning
the **rendered** chips gives **9, one template**; the rest are injected at
render time and resolve fine. Only rendered text proves a break.

Fixed in the DB (readback-confirmed) and in the seeding migration. The
morning audit now scans rendered chips for unresolved placeholders.

**Today's 4 stored chips keep the old text** until the next scorer run — I
chose not to rewrite a `primary_play` JSON blob on live NFL games mid-slate
