## 1 · "Dropping NCAAB ML sounds like quitting" — and the framing was mine

Andy, on §6.8 of yesterday's log: *"what do you mean dropping ncaab ml that
sounds like quitting and giving up which is unsat."*

He is right, and it was never a proposal. "Drop NCAAB favourite ML" is a
question the `NCAAB_ML_TIER_CAP` docstring asks, and my answer yesterday was

The right move was the one he was pointing at: stop asking whether to quit
the market and find out where the edge is. That went somewhere I did not
expect.

### 1.2 The client never got the 11-06 fix

Checking that boundary is what found this. `ADJ_EM_TO_MARGIN` replaced a
`/3.0` divisor in `ncaab_game_context` on 11-06 on measured grounds — `/3`
was *"wrong by ~3x"* and *"fabricated an 11.77-point spread_edge on every
game."* `app/index.tsx:4212` carried **the same divisor** in its own NCAAB
branch and nobody changed it. Thirteen days.

### 1.3 And it subtracted a pair every other writer sums

`projected_spread` is a home **margin** (+10 = home by 10). `close_spread`
is a home **handicap** (-10 = home laying 10). Opposite-signed, so
agreement **sums to zero**:

```
pipeline   abs(projected_spread + close_spread)             sum
NBA path   nrGap + marketSpread                             sum, commented
MLB        spread_delta = projected_spread + close_spread    "load-bearing"
client     predictedSpread - postedSpread                   THREE sites
```

MEASURED on 454 post-fix NCAAB games:

```
                           client (subtract)   pipeline (add)
mean |spreadEdge|               26.22 pts         2.91 pts
mean spreadMismatchScore        80.97             61.52
PINNED at the 85 ceiling      378/454 = 83%      59/454 = 13%

by spread size:  0-3  28% pinned | 3-6  78% | 6-10 100% | 10-20 100% | 20+ 100%
```

`spreadMismatchScore = min(85, 40 + |edge|*8)` carries **0.65 weight** into
`modelMismatch`. **Every NCAAB game with a spread of 6 or more produced the
identical maximum score** — 64 distinct values across the whole slate where
the correct formula gives 243. The signal could not discriminate between
games at all, while presenting as maximum confidence.

The fallback path had a second defect stacked on it: `spreads` is built with
`Math.abs(point)`, a **magnitude**, which cannot express a side — correct by
accident for home favourites, doubly wrong for away ones. It now takes the
signed home point, as the fanmatch path already did.

One site was sport-generic, so I read MLB's convention before touching it
rather than assuming NCAAB's applied. `game_context.py` documents the same
signs as load-bearing and empirically verified, so the sum is right there
too — but that had to be checked, because the edge sign genuinely does
differ by sport elsewhere.

### 1.4 A guard, because a comment is not one

`ncaab_game_context.py --self-test` gains **3 client-parity cases that read

Both self-tests now run unconditionally. My first version was

reported one defect while hiding another.

**7/7 + 3/3.** Shipped as `87c81bde`.

### 1.5 Not shipped, on purpose — the refit

Re-fitting `ADJ_EM_TO_MARGIN` on 614 rows, two independent targets agreeing
and split-half stable:

```
vs actual final margin   slope 0.863  intercept +2.35
vs posted close_spread   slope 0.840  intercept +3.07
first half  0.893/+2.44 and 0.848/+2.73
second half 0.837/+2.28 and 0.837/+3.17
```

The intercept is home-court advantage and is currently **zero**, which is
why all **39 side flips (6.4% of games) run away→home on small negative
gaps**. It would cut the phantom disagreement feeding `sweat_score` from
2.85 to 2.13 points, and from **6.51 to 3.01 on heavy away favourites**,
where more than half the apparent edge is the constant being wrong:

```
gap band      n    mean actual   gap*0.97   refit    market close
-99..-10     40      -5.83       -13.74     -9.87      -7.22
 -3.. +3     95      +1.08        +0.21     +2.54      +2.72
+20..+99    198     +27.90       +28.51    +27.71     +27.97
```

**But it changes which side we pick on 39 games**, which is a selection
change, not a bug fix — so it does not go in on my say-so. And the honest
framing is narrow: MAE against actual margin improves only 9.917 → 9.778,
and **the close still beats both at 9.493.** Market agreement is not
accuracy. On the 39 flips the refit picks the winner 22 times to 17 —
directionally right, n far too small to claim.

Andy's call, with the numbers on the table rather than a question mark.
