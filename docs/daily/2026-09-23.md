## Afternoon/evening — reads, passes, and a mutation-after-event incident

### The pass problem, root-caused and closed

Andy: "why was there 6 passes, that is unsat" then "can we ensure a pass
or mislabelled pass will never happen again".

Chain, measured not guessed:

  1. `_lr_predict_total` imputes every missing feature to its training
     median. With ALL features missing it emits a CONSTANT, p_over =
     0.4718, which sits inside the [0.45,0.55] coin-flip band.
  2. `apply_mlb_total_lr_override` reads that as "the model sees a coin
     flip" and demotes the ensemble's pick to COVERAGE.
  3. COVERAGE mapped to call_market='pass'.

36 of 178 games since 08-01 carried p_over = 0.4718 EXACTLY. 34 were
published as "engine passed"; 22 had a PRIME pick underneath, one at
conviction 97. Removing only those takes the MLB no-play rate from
27.4% to 8.4%.

Universal — same function, every sport, failing in two directions:

      MLB/NFL/NCAAF TOTAL  0.4718/0.4724/0.4911  -> KILLS the pick
      MLB/NFL/NHL/NBA ML   0.4284/0.5599/0.6024  -> INVENTS one

NHL reaches p_home=0.6024, a STRONG home call, from four imputed
medians and nothing else.

Fixes shipped:
  * `a7ed360a` no-data guard — a blind model returns None; the caller
    keeps the ensemble's own pick. Exact test (match the blind constant
    to 1e-9), not a threshold: NCAAF totals run 65% imputed in healthy
    operation, so any percentage cutoff would silence that sport.
  * `70b49f43` a PASS now requires that NO PICK EXISTS. Exactly two
    sites in the pipeline can write one and both are gated on absence.
    NFL had solved this on 09-16 for COVERAGE only; MLB never got it.
  * `193cfa01` prose must describe the call; line-only drift is
    corrected in place rather than discarding the analysis.
