## The two root causes worth remembering

**A V8-only date idiom cannot be caught off-device.** `new Date(x.toLocaleString('en-US', {timeZone:...}))`
works in node and in a browser and returns Invalid Date on Hermes. One
occurrence in `app/index.tsx` made the NCAAF week map never match, so the Games
tab fell back to 7-day arithmetic and showed 1 game out of 56. Type-check,
lint and node all pass on it. Grep for the pattern.

**A missing badge row is not always a rendering bug.** NHL had no
`*SituationalCard` at all while NFL/NCAAF/NBA each had one. Check whether the
component exists before debugging why it is empty — and note that NBA (B91) and
NCAAF (B92) badges *do* have components, so those are field-population
questions instead.
