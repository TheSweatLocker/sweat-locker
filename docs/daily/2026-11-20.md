## §2 — I broke the Sweat Card generator (`b5417ad5` → fixed `b51ed8b5`)

`stderr_tail` in `workflow_heartbeat` had the answer all along:

```
generate_sweat_card.py      rc 1  duration_s 0
refresh_yesterday_recap.py  rc 1  duration_s 0   (imports the above)
  SyntaxError: unterminated string literal  (line 5560)
```

A replacement field spanning two lines with same-type nested quotes — **PEP
701, legal from 3.12; CI pins 3.11**. My interpreter is 3.14, so it compiled
clean locally, was byte-identical to HEAD, and ran to completion here while
being unparseable on the runner. **Today's Sweat Card was built only by my
local run at 22:04** — the pipeline hadn't built the home screen all day.

`py_compile` **and** `ast.parse(feature_version=(3,11))` both accept it on
3.12+ (measured) — a local syntax check gives a false all-clear. Two guards:
`daily_card.yml` byte-compiles with the same 3.11 that imports the scripts,
and `check_ci_python_compat.py` walks tokens for the three things PEP 701
relaxed. Two more latent instances found and fixed.
