### 1a — NYG @ LA had side=AWAY with label='LA -7'  🔴→✅

`nfl_game_context` rows: exactly one mismatch, so the normalizer written

## 2 — nfl_game_picks was empty for two weeks  🔴→✅

24 rows total. 23 preseason, **one** regular-season row (09-09).

Root cause: batch upsert 400'd on **PGRST102 "all object keys must
match"** — `build_pick_row` and `build_skip_rows` emit different shapes
and `is_lock_of_week` is added to only one row. `upsert_picks` swallowed
it and returned 0, script exited 0, and the workflow's
`|| echo "play_of_day failed"` never fired.

Fixed: union keys across the batch; raise `PickWriteError` instead of
returning 0; mask removed from the workflow. Also `_side_from_play` now
trusts `primary_play.side` over the label (it was copying the stale-label
bug into the ledger), `_pick_line` prefers `primary_play.line` ('rl' fell
through to None), and `grade_pick` handles 'rl' at all — those picks sat
pending forever.

Backfilled weeks 1-3 through the same `build_pick_row` path. Week 1
11-6, Week 2 10-6, season 21-12 (63.6%).

## 3 — THE PROP LEAK  🔴 (root cause, partially fixed)

Andy: *"What is creating prime props after and calling them wins, thats
poisonous."*

`fetch_mlb_player_recent` pulled a player's whole season gameLog,
newest-first, `vals[:n]` — **no upper date bound.** Once a game was
played it became the newest entry, so the game being predicted sat
inside its own L5/L10 window. Those fields feed the LR model that
**overrides tier**.

    l5_hit_count = 3  →     6-19    24.0%
    l5_hit_count = 4  →   966-239   80.2%
    l5_hit_count = 5  →   308-4     98.7%   ← tautology

"5 of the last 5 hit" includes the one being predicted.

**Ruled out first, in this order** — worth repeating as a method:
- outcomes real: `final_value` vs MLB box scores — 09/20 1,337/0 mismatch,
  09/16 1,219/0, 09/15 1,394/1
- grading correct: 16,507 grades recomputed, **0 disagreements**
- not late row creation: PRIME created after the game did *worse*
- not duplicates: 335 dup rows in 18,105

Corroboration: PRIME beat market-implied by +8.6 at ≤-250 rising
monotonically to **+31.6** at ≥-110 — edge growing as the market gets
less certain is backwards for skill and is the fingerprint of leakage.
Control group: never-enriched rows sit at **-1.4** vs market (efficient);
enriched at **+19.3**.

Timing made it near-universal: of 12,498 enriched graded rows, **12,474
had lookback written AFTER first pitch.**

Fixed: `before_date` bound on both fetches (the rows variant feeds the
user-facing L5/L10 table, which was showing the result of a still-open
prop). LR tier authority revoked by default — the coefficients were fit
against a feature that contained the answer.

**Still open:** tiers already written 09-03→09-22 are hindsight-picked.
Model needs retraining. See BACKLOG B3/B4.
