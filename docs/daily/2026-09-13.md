## Root causes

- **POTD Frank Thomas** — `generate_potd_narrative.build_prompt` fell through to a minimal stub for non-MLB sports (no strict FACTS block, no tout-language ban, no "argue-for-pick" rule)
- **NFL Prop Jerry showing 2** — my earlier NFL PATCH of 305 rows from tier-name → 'BACK' was semantically wrong. Also flat: `mlb_pipeline_props.tier` for MLB was fine; NFL was different code path
- **Refit=0 hidden PRIMEs (5-day bleed)** — TRIPLE ROOT CAUSE:
  1. `apply_prop_refit.compute_refit` clamped negative raw scores to literal 0.0 via `max(0.0, min(95.0, conv))` and wrote them to DB. `v_mlb_props_publishable.display_conviction = COALESCE(refit, conv)` — COALESCE substitutes only on NULL, not zero — so those rows displayed with conviction 0 and sank to the bottom of the app's `.order(display_conviction, desc)` sort. App-hidden.
  2. `apply_prop_refit.run` fetched props with `limit=500`, silently capped to first 500 rows by PostgREST — even though today's slate has 3252 rows. So ~85% of props never even re-entered the refit path, letting stale zeros persist forever.
  3. Backfill scrub logic only cleared zeros when the current run returned None — but the pagination bug meant most zeros never got that chance.
- **Pitcher PRIME wipe (today's collapse)** — `sweep_prop_coverage.sweep()` fetched existing rows without pagination (default 1000 cap). Full Sunday slate has 3252 rows — the ~2200 past position 1000 were invisible to `existing_by_key`. For pitcher props inserted later in the day (post-lineup confirmation), `existing_by_key.get(key)` returned None → PATH B (insert stub) fired with `tier='COVERAGE'`, `conviction=0`, `signals={}`. The `on_conflict + merge-duplicates` clause added in 863f7cd1 (9/12) turned that stub payload into a DESTRUCTIVE UPSERT — Jackson Jobe outs_under conv=83 morning → SKIP conv=0 after the 15:43 UTC sweep. Every sweep run this class of overwrite ran.
- **Sharp Card missing NFL PRIME/STRONG (JAX, DET, LAC)** — `_fetch_all` NFL/NCAAF SELECT was missing `close_spread`. Composer's juice-swap branch (line 809) reads `close_spread` to convert heavy-fav ML picks (< -300) into spread picks. With column absent, `g.get('close_spread')` returned None → hit the "no spread → skip" `continue`. Symptom: heavy-fav STRONG+/PRIME picks silently dropped from card.
- **Sharp Card MTD drop** — 9/9 was one bad night, 33-leg oversized card (double normal), all 5 Under totals lost + 5 juiced MLs lost = -12.92u. Not a systemic bug — variance + card sizing.
- **Dawg 2-day gap** — every game today has Jerry seeing the favorite winning either strongly (10 games) or below the 1.0-mag gate (3 games). Chalk-heavy Sunday. Correct no-pick.
