Graded on the side the money was on, against that side's own base rate, with
the real closing moneyline so the number is ROI and not just a hit rate
(`audit_sharp_money_edges.py`):

| sport / market | divergence ≥ +0 | heaviest bucket |
|---|---|---|
| MLB ml | −4.7% ROI (n=718) | div ≥ +20 → **40.2%, −18.8%**, n=164 (clears its band) |
| MLB rl | −0.4pp hit | no price stored → ROI n/a |
| NCAAF ml | −23.5% ROI (n=532) | div ≥ +10 → 33.3%, −24.0% |
| NCAAF rl | −3.7% ROI (n=535) | div ≥ +20 → +3.0%, n=89 (inside band) |

MLB ML decays monotonically as divergence grows: −1.0 → −2.2 → −2.2 → −5.5 →
−11.2pp. That replicates `project_sharp_money_is_a_fade_929`.

## The SP+ / EPA conjunction: looked real, died under testing

`NCAAF ml · divergence ≥ +5 AND SP+ gap agrees` showed 72.1% against a 44.1%
side base — **and it survived the ROI check at +5.7%**, which I had predicted
would expose it as favourite selection. It did not die there. It died in
`audit_sharp_gap_robustness.py`:

- bootstrap 95% CI on ROI **[−10.6%, +16.5%]** — zero inside
- temporal split: +0.42% early vs +5.45% late (div ≥ +10: **−3.43% early**)
- **top 3 winners contribute 133% of the total profit** — the entire edge is
  three games
- the ATS twin of the same cell is −5.2%

One cell out of ~24 clearing in-sample is what randomness produces. Not
actionable. Not published.

## Root-cause bug found and fixed: the split-flag guard was sport-blind

`ensemble_scorer._handler_split` carried a 2026-08-31 MLB quarantine keyed on
the bare string `signal_key == 'sharp_split_confirmed'`. The live signals in
every other sport are `sharp_split_confirmed_nfl` / `_ncaaf` / `_ncaab` /
`_nhl`, and nothing strips the suffix. So outside MLB **neither** guard
matched:

1. **Double counting** — both split signals emitted an Opinion for the *same*
   flag, one flag pushing a side twice. (On MLB the same happened on TRIPLE
   flags specifically.) This is the failure `_handler_scenario` already
   documents for scenarios.
2. **Weight misattribution** — a 1-source LEAN flag was scored with
   `sharp_split_triple_confirmed`'s registry hit_rate / n / tier.

Exposure: NCAAF 354 non-neutral flags of which only 23 are TRIPLE; NHL 99;
NFL 4.

**Fixed** by routing each flag to exactly one signal by source count. Verified
on real flag rows: MLB TRIPLE 2 opinions → 1; MLB LEAN still 0 (quarantine
intact); NCAAF TRIPLE 2 → 1; NCAAF LEAN now fires at strength 0.4 on the
*confirmed* record instead of borrowing TRIPLE's.

### The quarantine was deliberately NOT extended

`audit_line_flags.py` grades flags on the side the engine actually bets
(RLM_* / PUBLIC_MOVE_* inverted, as `_flag_to_candidate` does). 1-source flags
run **opposite ways by sport**:

| | hit | ROI | n |
|---|---|---|---|
| MLB LEAN (1 src) | 42.3% | **−24.2%** | 189 |
| NCAAF LEAN (1 src) | 64.5% | **+18.5%** | 166 |

NCAAF LEAN holds in both halves of the season (+9.1% early, +24.3% late, late
CI excludes zero). Blanket-extending an MLB-derived quarantine would have
switched off a signal that is earning. Same lesson as the LR-warn cap
(`project_lr_warn_cap_sport_blind_1009`): measure per sport, gate per sport.

### Open question raised by the same audit

MLB 2-source CONFIRMED on the **full** sample is 53.7% / **ROI +4.7% / n=397**,
which disagrees with the 30-day window the 2026-08-31 quarantine was fit to.
1-source is still clearly bad. The quarantine is left in place rather than
flipped on one in-sample read, but the 2-source half of it is now a live
question. Noted in code at the guard.

Also: `sharp_split_triple_confirmed_ncaaf`'s registry record was built from
firings that included LEAN flags, so its stored hit rate is contaminated and
wants a refit now that routing is correct.

## THE STRUCTURAL FINDING: money-flow signals INVERT between MLB and NCAAF

Two independent signal families, measured separately the same day, agree:

| | MLB | NCAAF |
|---|---|---|
| 1-source split flags (`audit_line_flags`) | −24.2% ROI, n=189 | **+18.5%**, n=166 |
| Heavy sharp divergence (`audit_sharp_money_edges`) | **fade** it: +6.5%, n=164 | **follow** it: fading loses −12.1%, n=89 |

No single cell clears its bootstrap CI. But the *inversion* replicates across
two unrelated datasets, and that is far stronger evidence than any one cell —
and it is directly actionable in a way a point estimate is not:

**any single global treatment of money flow is guaranteed to be wrong in one
of the two sports.** We currently treat it uniformly (follow the flag side,
with RLM_*/PUBLIC_MOVE_* inverted) in every sport.

This also explains the two older notes that looked contradictory:
`project_sharp_money_is_a_fade_929` (MLB) and
`project_sharp_money_football_opposite_930` (NCAAF +1.8%). They were never in
conflict — the sign is sport-specific.

### The fade, tested properly

A losing cell is only playable if betting against it earns. That is NOT the
mirror bucket: divergence is averaged over whichever sources reported, so on
MLB ml `div >= +20` is n=169 while `div <= -20` is n=17 — different games. So
the fade is graded by buying the OTHER side of the SAME games at its own
closing price:

| | fade ROI | median price | n |
|---|---|---|---|
| MLB ml, div ≥ +20 | **+6.5%** CI[−7.2,+20.2] | −123 | 164 |
| NCAAF ml, div ≥ +5 | −12.8% CI[−21.6,−3.7] | −156 | 331 |
| NCAAF rl, div ≥ +20 | −12.1% | −110 | 89 |
| NFL rl, div ≥ +5 | +5.5% CI[−17.1,+25.6] | −110 | 76 |

NCAAF **ml** loses both following AND fading — that market is unplayable on
vig alone, consistent with `project_ncaaf_ml_path_is_the_leak_930`. Read NCAAF
on the spread, not the moneyline.

Why the naive MLB fade looked better than it is: the public side wins 59.2%
but is priced at −158, where breakeven is 61.2%. Hit rate alone would have
called that an edge.

## Data notes found along the way

- `mlb_game_context` holds **39 rows** — it is a current-games table, not
  history. Joining MLB analysis through it silently yields ~50 rows out of
  42,736 split readings. MLB/NCAAF/NHL join `*_game_results.game_id` directly
  (675/679, 469/483, 97/97); **NFL is 0/90** and must bridge via
  `nfl_game_context` (90/90) — the known NFL/NCAAF id split.
- `public_splits_archive.current_odds` exists but is **NULL on every row**.
  Prices for ROI must come from the results tables
  (`close_home_ml`/`away_ml_close`). Coverage since 8/1: NCAAF 518/573,
  MLB 789/807, NFL 274/274.
- No spread-price column exists in any sport. Football ATS uses the −110
  convention; MLB runline ROI is reported `n/a` rather than invented, since
  runline prices swing +100 to +160.
- NHL flags: 99 non-neutral, **all 99 fail to join** `nhl_game_results` — an
  id-scheme gap, so NHL gets no verdict here.
- NCAAF carries genuine −2500/−5000 moneylines (FBS/FCS mismatches), plus 31
  rows at −100000 which are implausible as book prices. Not what killed the
  finding above, but any ROI claim should band the price.
