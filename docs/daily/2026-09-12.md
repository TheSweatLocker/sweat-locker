## Root causes

- **L5/L10 graphs missing** — `generate_prop_jerry_synthesis.run_for_sport` fetched props with `limit=5000` in query params, but PostgREST silently caps `.select()` responses at 1000 rows regardless. Today's 2807 MLB props → first 1000 got synth (dominated by SKIP tier under tier.asc order) → STRONG-tier pitcher props past row 1000 never got `prop_jerry_reads` rows → no `render_sections.recent_form` → no graph. Same class landmine hit in [feedback_grading_zero_fail_912](../../memory/feedback_grading_zero_fail_912.md).
- **Sharp tab 4-2-1 wrong** — same PostgREST 1000-row cap in `aggregate_daily_records._load_props_by_sport`
- **Grader missing 45 props** — same PostgREST 1000-row cap in `grade_props.fetch_ungraded` + `STAT_MAP_MLB` missing batter families (rbis/tb/hr coverage stubs graded as "no data")
- **3000 dup-key violations** — `sweep_prop_coverage.py:501` POSTs to `mlb_pipeline_props` with `Prefer: resolution=merge-duplicates` header but no `?on_conflict=<uniq-cols>` in URL — PostgREST needs both. Without on_conflict, plain INSERT runs and existing rows return 23505.
- **Batter families surfacing** — my (Claude) earlier STAT_MAP expansion in `backfill_prop_lookback` added `rbis/tb/hr/runs/batter_ks`, which populated `_stat_last10` for those families, which unlocked tier promotion for prop types the app had never rendered. Andy caught within minutes. Reverted.
- **Writeup vs primary_play mismatch (5 of 15 MLB games)** — under investigation. Suggests writeup generator (`short_read`) and primary_play resolver (`call_market/call_side/call_line`) land on different picks. Not a display glitch; two separate generation paths.

## Lessons for the runbook

- **Third PostgREST landmine site fixed today.** All three (grade_props, aggregate_daily_records, generate_prop_jerry_synthesis) were the same class bug: `limit=N` in query params doesn't override the server's 1000-row cap; you need Range-header pagination. Any future fetch against `mlb_pipeline_props` or `prop_jerry_reads` should default to paginated. Captured in [feedback_grading_zero_fail_912](../../memory/feedback_grading_zero_fail_912.md) + [feedback_prop_graph_rendering_912](../../memory/feedback_prop_graph_rendering_912.md).
- **My mistake — STAT_MAP expansion cascaded.** Adding batter families to `backfill_prop_lookback.MLB_STAT_MAP` populated L5/L10 for those families → unlocked PRIME/STRONG promotion → surfaced alien prop types on Sweat Card. Andy caught in minutes. Won't touch MLB_STAT_MAP without explicit user approval.
- **My mistake — UnboundLocalError crashed synth.** Introduced when trying to also count template writes in `done` counter. Now always run `python -c "import ast; ast.parse(...)"` before shipping + scan for variable init sites when moving accumulator logic.
