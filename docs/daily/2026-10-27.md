# Afternoon — G1 shipped, and the engine finding

## Receipts were DEAD for two days, and it was my migration

`public_receipts` took zero writes on 10-25 and 10-26, every surface.
`20261025a` (mine, 10-25) replaced the full unique constraint with a
**partial** unique index; PostgREST's `on_conflict=` can only pass column
names, not an index predicate, so every write returned `400 42P10`.
`capture()` is fail-soft, so cards published and the only trace was a log
line. My verify block checked the index existed and that no duplicates
existed — it never attempted an upsert.

Fixed in `3971bec7`: first-write-wins now runs inside `capture()` via
`_live_keys()`. 11 receipts recovered; republish is a clean no-op.

## ⭐🚨 CONVICTION WORKS — ON BASEBALL ONLY

Priced ML receipts since 09-19, real stored prices, per-row breakeven.
Pooled it is the best-looking finding in the product, with no cliff and a
clean control:

    ML conv >=60  65.4% n=347 +10.33% CI[60,70] CLEARS
    ML conv >=80  76.8% n=69  +25.25% CI[66,85] CLEARS
    control <80   60.1% n=459  +4.32%           does not clear

Then decompose:

    >=80 MLB            80.4% n=56  +31.15%  CLEARS
    >=80 excluding MLB  61.5% n=13   -0.15%
    non-MLB at EVERY cutoff 50..80: flat, nothing clears, no gradient

Root cause — the scales are not comparable:

    sport   median  max   >=80
    MLB       75     97   29.8%
    NCAAF     67     87    7.8%
    NHL       59     84    1.4%
    NFL       62     79    0.0%
    NBA       52     62    0.0%

NBA's whole range is 50-62. NFL tops out at 79. **Neither can reach the band
that works in MLB even in principle.** So every cross-sport conviction gate
and every per-sport tier threshold is comparing numbers that are not on the
same scale — which is why the engine looks random outside baseball.

And `tier` on the same rows is noise: STRONG −1.69%, LEAN −1.92%,
COVERAGE +9.05%, PRIME +9.13%, none +18.88%. **We gate on the field that
does not work and ignore the one that does.**

Refitting conviction per sport, against each sport's own outcome
distribution, is the substance of B225. It is a model change, not another
measurement.
