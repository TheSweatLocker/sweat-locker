## 1. QUALITY OVER QUANTITY — measured, and it works

**NFL props, out-of-sample walk-forward by date, ranked within each game by
the EXISTING conviction:**

| selection | n | hit% | breakeven | ROI |
|---|---|---|---|---|
| **top 1 / game** | 107 | 51.40% | 51.37% | **+2.05%** |
| **top 2 / game** | 214 | 51.87% | 50.98% | **+1.61%** |
| top 3 / game | 321 | 50.78% | 51.41% | −1.40% |
| top 5 / game | 535 | 48.41% | 51.76% | −6.34% |
| **ALL — what ships today** | 4,403 | 48.29% | 49.98% | **−3.69%** |

Monotonic decay with K. **The NFL scorer already ranks correctly inside a
game; publishing 2,789 props instead of the top 1–2 is what destroys it.**

A gradient-boosted model fitted on 21 pre-game features (incl. opponent
defensive EPA/ypg/sacks) did WORSE than random — discarded. The existing
conviction is the better ranker; the fix is the cap, not a new model.

**FIX:** cap published props at the top 1–2 per game per sport, by
conviction. Nothing else about the scorer needs to change for NFL.

### Why this cannot simply be switched on everywhere

| sport | conviction > 0 | games rankable |
|---|---|---|
| MLB | 15,807 / 34,443 | 743 / 814 |
| NFL | 4,939 / 5,770 | 136 / 137 |
| NBA | 1,512 / 24,491 | 55 / 123 |
| NHL | 665 / 83,986 | 49 / 260 (**1 distinct tier**) |

MLB and NFL can rank. NBA half can. NHL cannot. **The blocker is scorer
coverage, not data.**
